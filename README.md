## 01 / CURRENT FOCUS

- **Web engineering** — building and improving web experiences, application logic, and integrations.
- **Automation** — reducing repetitive work through scripts and practical tooling.
- **Application security** — learning how vulnerabilities occur, validating findings responsibly, and documenting remediation.
